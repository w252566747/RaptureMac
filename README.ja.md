# RaptureMac

[中文](README.md) · [English](README.en.md)

macOS 用のネイティブなスクリーンショット／貼り付け画像ツールです。ウィンドウをクリック、または範囲をドラッグすると、キャプチャ結果を移動可能なフローティング画像として画面に残します。

> 非公式プロジェクトです。Windows 版 Rapture から着想を得ていますが、元ソフトウェアの作者との提携・承認関係はありません。

## 機能

- ウィンドウキャプチャ：クリックした位置のウィンドウを取得します。重なったウィンドウも、画面に見えている状態のまま含まれます。
- 範囲キャプチャ：ドラッグした範囲を取得します。デスクトップの空白部分をクリックすると画面全体を取得します。
- フローティング画像：キャプチャは元のウィンドウ位置に残り、画像部またはタイトルバーから自由に移動できます。
- 複数キャプチャ：複数の貼り付け画像を同時に残せます。Dock アイコンを右クリックして「次のキャプチャ」を選べます。
- 注釈：`⌘` を押しながらドラッグすると赤いフリーハンド線、`⌘⇧` を押しながらドラッグすると水平・垂直の直線を描けます。
- 編集：最後の線の取り消し、右クリックによるコピー、PNG 保存、貼り付け画像の終了に対応しています。
- ダブルクリック：貼り付け画像をダブルクリックすると、注釈を含む画像をクリップボードへコピーして閉じます。

## 使い方

1. `RaptureMac.app` を開くと、最初のキャプチャモードが始まります。
2. ウィンドウをクリックするか、範囲をドラッグします。
3. 作成された貼り付け画像を移動・注釈・右クリックでコピー／保存できます。
4. 次のキャプチャを作成するには、Dock の RaptureMac アイコンを右クリックして「次のキャプチャ」を選択します。

## 権限

RaptureMac には macOS の画面収録権限が必要です。

**システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音 → RaptureMac**

権限を許可した後は、アプリを終了して再度開いてください。

## ローカルビルド

必要環境：macOS 14 以降、Xcode Command Line Tools、Swift、ScreenCaptureKit。

```zsh
git clone https://github.com/YOUR_ACCOUNT/RaptureMac.git
cd RaptureMac
./build-app.sh
open .build/RaptureMac.app
```

ビルド結果は `.build/RaptureMac.app` に作成されます。これは開発用の自己署名ビルドです。他のユーザーに配布する場合は、将来的に Developer ID 署名と公証を推奨します。

## セキュリティに関する注意：未署名と Gatekeeper

現在の Release は **Apple Developer ID で署名されておらず、Apple の公証も受けていません**。そのため、初回起動時に macOS Gatekeeper が「開発元を確認できない」または「Apple は悪意のあるソフトウェアが含まれていないことを確認できない」と表示することがあります。

- 本プロジェクトの公式 GitHub Release からのみダウンロードしてください。
- ダウンロード後、Release に記載された SHA-256 値を確認してください。
- 配布元と SHA-256 値を信頼できる場合に限り、**システム設定 → プライバシーとセキュリティ → このまま開く** から手動で許可してください。
- 会社や学校で管理されている Mac では、未署名アプリを完全に禁止している場合があります。その場合はソースからビルドするか、将来の署名・公証版をお待ちください。
